# مشاركة أكتر من ملف/مجلد في لينك واحد

## اللي اتغيّر
- زرار المشاركة (وقايمة كليك يمين) بقى شغّال لما تحدد **أكتر من عنصر** (Ctrl/Shift + كليك أو تحديد بالماوس).
- النافذة بتديك: اسم للمجموعة (اختياري) + نفس خيارات الرابط (المدة، عرض/تنزيل، باسورد، بيانات الزائر، شخص واحد/مرة واحدة).
- المستلم بيفتح لينك واحد يشوف **مجلد افتراضي** باسم المجموعة: المجلدات فوق، الملفات تحت، والمجلدات بتتفتح بكل اللي جواها، ومسار تنقّل (breadcrumb) وزرار "تنزيل كـ ZIP" للكل.
- لو اخترت مجلد وملف جواه، بياخد المجلد بس. ولو فضل عنصر واحد بعد كده بيتعمل رابط عادي.
- الملفات مبتتنسخش. لو عنصر اتحذف بيختفي من المجموعة، ولو كلهم اتحذفوا الرابط بيموت.
- "روابطي المشاركة" بتعرض المجموعة بأيقونة مجلد وعدد العناصر.

## التركيب
**الباك إند (Laravel)** — انسخ ملفات `backend/` فوق المشروع (أو طبّق `backend.patch`) ثم:
    php artisan migrate
(ميجريشن جديد: 2027_01_13_100000_add_bundles_to_drive_shares — بيضيف عمودين لـ drive_shares وجدول drive_share_items.)

**الفرونت (React)** — انسخ ملفات `frontend/` فوق المشروع (أو طبّق `frontend.patch`) ثم:
    npm run build   وارفع على Vercel

## صفحة المستلم (تحديث)
- زرار "إخفاء العرض / إظهار العرض" فوق المعاينة (الملف يفضل محمّل، بس بيتطوي).
- قائمة العناصر: زرار إخفاء/إظهار، عرض قائمة أو شبكة، وبحث سريع لو العناصر أكتر من 6.
- عدّاد المجلدات والملفات في أعلى الصفحة.
