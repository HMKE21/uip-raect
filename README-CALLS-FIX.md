# إصلاح المكالمات (صوت في اتجاه واحد / فيديو أسود)

انسخ الملفات دي فوق نفس المسارات في مشروع الـ React (5 ملفات):
src/lib/calls/callEngine.js · src/context/CallContext.jsx · src/context/callCtx.js · src/components/calls/CallUI.jsx · src/styles/css/calls.css

## اللي اتغيّر
1. تشغيل صوت الطرف التاني: الـ <audio> بيتجهّز من لمسة "اتصال/رد" (مهم لـ iOS/Android WebView)، ولو المتصفح رفض يشغّل الصوت بيظهر زرار "اضغط لتشغيل صوت المكالمة" وبيعيد المحاولة مع أي لمسة. العنصر مبقاش display:none.
2. الفيديو الأسود: لما الـ track يبدأ ياخد باكيتات فعلًا (unmute) بنربطه تاني بالـ <video> ونعمل play().
3. مراقب للوسائط: لو الاتصال "connected" بس مفيش صوت داخل 8 ثواني → المتصل يعمل ICE restart، ولو لسه → عن طريق TURN relay (لو TURN متظبط). المستلم بيطلب ده من المتصل بإشارة state.
4. لوحة تشخيص: افتح الموقع بـ ?calldebug (أو localStorage.setItem('uip.call.debug','1')) وهتشوف أثناء المكالمة: نوع المسار (host/srflx/relay)، هل TURN متظبط، وبايتات الصوت/الفيديو داخل وخارج.

## تشخيص السبب الحقيقي
- TURN: `TURN yes/NO` في اللوحة. لو NO → لازم تحط مفاتيح TURN في الباك (CF_TURN_KEY_ID + CF_TURN_API_TOKEN أو METERED_* أو TURN_URLS+TURN_SECRET). من غير TURN، شبكات الموبايل/الجامعة غالبًا هتدّي صوت في اتجاه واحد أو فيديو أسود.
- لو audio in = 0 عند طرف وout > 0 عند الطرف التاني → المشكلة في الشبكة بين الطرفين (TURN)، مش في الكود.
- لو audio in بيزيد والصوت مش مسموع → زرار "اضغط لتشغيل الصوت" أو خرج الصوت/السماعة في الجهاز.
- لو video in/frames بيزيدوا والشاشة سودا → ابعتلي المتصفح/الجهاز.
